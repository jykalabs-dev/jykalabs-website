# Jyka Labs logo kit

The Progress Ring mark: JL inside a ring that is three-quarters complete. Chosen 16 Nov 2026.
Use the plain files on light backgrounds and the `-on-dark` files on dark ones. Keep clear space of at least
the height of the J around the logo, and don't recolour, stretch, rotate or add effects (no glow, no shadow).

## Vector (SVG)

| File | Use |
| --- | --- |
| `logo-horizontal.svg`, `logo-horizontal-on-dark.svg` | Website headers, email signatures, documents, slides |
| `logo-stacked.svg`, `logo-stacked-on-dark.svg` | Square spaces, posters, title slides |
| `logo-mark.svg`, `logo-mark-on-dark.svg` | The mark alone, where the name is already nearby |
| `avatar.svg` | Social profile pictures (fits a circle crop) |
| `app-icon.svg` | Phone home-screen icon (full-bleed square; phones round the corners) |
| `favicon-small.svg` | Bold, flat version for 16 to 48 px (browser tabs) |

The wordmark (JYKALABS) is set in Plus Jakarta Sans (free, OFL, in `docs/fonts/`) and converted to outlines, so the SVGs
look the same everywhere, with no font needed. They are safe to send to printers and other designers.

## Raster (PNG, transparent background) in `png/`
